# Hockey Patins UE Horta 2026–2027

Webapp estàtica de les categories i clubs vinculats als calendaris 2026–2027 de la UE Horta.

- Idioma inicial: català.
- Selector CAT | ES a la capçalera.
- Preferència d'idioma desada al navegador.
- Cerca per club, ciutat, localitat, adreça o categoria.
- Navegació a Google Maps.
- No requereix servidor ni base de dades.

Obre `index.html`.

Feta per una IA: 2 minuts la sortida inicial, i després he invertit algo de temps en petits refinaments (...)
